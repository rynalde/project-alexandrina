### The setup

One image. **No hand-crafted augmentations** — no crops-and-colour-jitter pairs like BYOL needs. The image is cut into patches; with 16px patches a 224px image becomes a 14×14 grid of tokens.

### Step 1 — the masks

- — <Highlight>4 target blocks</Highlight>, each 15–20% of the image, aspect ratio 0.75–1.5.
- — <Highlight>1 context block</Highlight>, 85–100% of the image, square — then every target patch is removed from it.

Targets are **big** so they are semantic (a whole part of an object, not a stray pixel). The context is **spread out** so it is informative. The paper found both matter.

<MaskSampler />

### Step 2 — three networks

- — **Context encoder** (a ViT) sees *only* the context patches.
- — **Target encoder** (same architecture) sees the *full* image. Its weights are an EMA of the context encoder.
- — **Predictor** (a narrow ViT, width 384) receives the context tokens plus one <Kbd>mask token</Kbd> per target patch, each tagged with its position. It runs **once per target block** (4 times) and outputs a predicted representation for every patch of that block.

<PredictReveal prompt="Why cut the targets out of the target encoder's OUTPUT, instead of feeding only the target patches into it?">
Output tokens have already attended to the whole image, so each target representation is context-aware and high-level. Feed only the target patches in and you'd get low-level, local features. The I-JEPA paper calls masking the output crucial for semantic targets.
</PredictReveal>

### Step 3 — loss and update

The loss is the **average L2 distance** between predicted and target patch representations. Gradients update the predictor and the context encoder. The target encoder gets no gradient; after each step:

<Kbd>θ_target ← τ · θ_target + (1 − τ) · θ_context</Kbd>

with τ ramping from **0.996 to 1.0** over training.

Reading the official code is instructive: the target features are first normalized with layer norm, and the loss in the code is smooth L1, while the paper describes it as an L2 distance. Chapter 08's lab keeps the layer norm and uses a squared (L2) loss.

<EmaLab />

### Did it pay off?

A ViT-H/14 trained on ImageNet in **under 72 hours on 16 A100s**. Linear probe: **79.3%** top-1 after 300 epochs — above MAE's 77.2% after 1600 epochs.
