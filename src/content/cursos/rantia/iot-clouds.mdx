### Jornada de dados IoT

<Highlight>Device/Sensor → Gateway/Edge → Cloud Ingestion → Stream Processing → Storage/Analytics → Dashboard/API/Action</Highlight>

### Edge vs Cloud

- — **Edge**: decisões rápidas locais, filtragem, baixa latência, privacidade.
- — **Cloud**: escala, história, gestão de frota, integração, analytics pesados.

### Plataformas IoT Cloud

Uma plataforma gere: conectividade de dispositivos, identidade, ingestão de telemetria, processamento de streams, armazenamento, analytics, dashboards, APIs, regras e integração AI/ML.

Padrões das aulas:
- — Azure: IoT Hub, IoT Edge, Digital Twins, OPC UA.
- — AWS: IoT Core, Rules Engine, Greengrass.
- — Google: Pub/Sub, Dataflow, integração AI/ML.

### Digital Twins

Representação digital de um sistema físico para <Highlight>monitorização, simulação e análise</Highlight>. Liga-se ao conceito de sistema ciber-físico — o digital twin é a interface entre mundo digital e físico.

### Zero-trust security

Modelo de segurança onde nenhum dispositivo ou utilizador é confiável por omissão. Cada acesso é verificado.
